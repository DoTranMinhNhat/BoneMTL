1 Abstract

Bone tumor diagnosis from X-ray images is a challenging clinical task requiring simultaneous lesion detection, malignancy assessment, and tumor type identification. We present BoneMTL, a multi-task deep learning framework that jointly performs pixel-level segmentation and three-tier hierarchical classification on the BTXRD dataset. Our model uses a shared ResNet50 encoder with a U-Net decoder for segmentation and three classification heads for tumor detection, malignancy grading, and tumor type identification. We replace standard CrossEntropy with Focal Loss for the severely imbalanced 9-class Tier 3 classification and increase the segmentation loss weight to \(\lambda_{seg}=2.0\). Experiments show improvements across all metrics compared to the single-loss baseline.

2 Introduction

2.1 Clinical Context

Bone tumors affect patients of all ages and range from benign lesions requiring observation to aggressive malignancies demanding immediate intervention. Radiologists must answer three questions from a single X-ray:

  1. Is there a tumor? (detection)
  2. Is it benign or malignant? (malignancy grading)
  3. What type of tumor is it? (fine-grained classification)

These questions form a natural hierarchy — answering (2) only makes sense if (1) is positive, and (3) refines (2) further.

2.2 Motivation for AI

Manual reading of bone X-rays is time-consuming, subjective, and requires specialized expertise. Deep learning has shown strong performance in medical image analysis, but most existing work addresses only one task at a time. Multi-task learning allows a single model to solve all three problems simultaneously, sharing representations and reducing inference cost.

2.3 Contributions

  • BoneMTL architecture: shared ResNet50 encoder with U-Net segmentation decoder and three classification heads
  • Hierarchical loss: combined BCE, Focal Loss, and Dice+BCE losses weighted per task
  • Empirical analysis: ablation study on loss weights and Focal Loss gamma on the Vietnamese BTXRD dataset

3 Background & Preliminaries

3.1 Convolutional Neural Networks

A Convolutional Neural Network (CNN) applies learned filters to extract spatial features from images. For an input feature map \(X \in \mathbb{R}^{C \times H \times W}\), a convolutional layer computes:

\[ Y_{c'} = \sum_{c=1}^{C} W_{c',c} * X_c + b_{c'} \]

where \(*\) denotes 2D convolution, \(W\) are learned weights, and \(b\) is a bias term.

3.2 ResNet and Skip Connections

Deep networks suffer from vanishing gradients — gradients become exponentially small as they propagate through many layers during backpropagation. ResNet (He et al. 2016) solves this with residual connections:

\[ \mathbf{y} = \mathcal{F}(\mathbf{x}, \{W_i\}) + \mathbf{x} \]

The identity shortcut \(+\mathbf{x}\) ensures gradients flow directly to earlier layers, enabling training of very deep networks (50-152 layers). In BoneMTL we use ResNet50, which has 4 residual stages producing feature maps at resolutions \(\frac{H}{4}, \frac{H}{8}, \frac{H}{16}, \frac{H}{32}\).

3.3 U-Net Architecture

U-Net (Ronneberger et al. 2015) is an encoder-decoder architecture designed for biomedical image segmentation. The key insight is skip connections between encoder and decoder at each resolution level:

\[ \text{dec}_i = \text{Conv}(\text{concat}[\text{upsample}(\text{dec}_{i+1}),\ \text{enc}_i]) \]

This allows the decoder to recover fine spatial details lost during downsampling. BoneMTL uses the ResNet50 encoder features as skip connections into a 4-level U-Net decoder.

3.4 Multi-task Learning

Multi-task learning (MTL) trains a single model on multiple related tasks simultaneously. The total loss is a weighted sum:

\[ L_{total} = \sum_{t=1}^{T} \lambda_t L_t \]

The shared encoder learns representations useful for all tasks, acting as a regularizer and reducing overfitting. The \(\lambda_t\) weights control the relative importance of each task.

3.5 Loss Functions

3.5.1 Binary Cross-Entropy (BCE)

For binary classification with prediction \(\hat{y} \in [0,1]\) and label \(y \in \{0,1\}\):

\[ L_{BCE} = -[y \log \hat{y} + (1-y) \log(1-\hat{y})] \]

For class imbalance (e.g., malignant cases are rare), we use weighted BCE:

\[ L_{BCE}^{w} = -[w \cdot y \log \hat{y} + (1-y) \log(1-\hat{y})] \]

where \(w = \frac{N_{negative}}{N_{positive}}\) upweights the minority class.

3.5.2 CrossEntropy

For multi-class classification with \(C\) classes:

\[ L_{CE} = -\sum_{c=1}^{C} y_c \log \hat{p}_c \]

3.5.3 Focal Loss

Focal Loss (Lin et al. 2017) addresses class imbalance by down-weighting easy examples:

\[ L_{FL} = -\alpha_t (1 - p_t)^\gamma \log(p_t) \]

where \(p_t\) is the predicted probability for the true class, \(\gamma > 0\) is the focusing parameter, and \(\alpha_t\) is the class weight. When \(\gamma = 0\), Focal Loss reduces to weighted CrossEntropy. We use \(\gamma = 2.0\) for Tier 3.

Intuition: easy examples (high \(p_t\)) have \((1-p_t)^\gamma \approx 0\), contributing little to the loss. Hard examples (low \(p_t\)) have \((1-p_t)^\gamma \approx 1\), contributing fully. This forces the model to focus on difficult, rare classes.

3.5.4 Dice Loss

Dice Loss directly optimizes the Dice coefficient — a measure of overlap between prediction and ground truth:

\[ L_{Dice} = 1 - \frac{2|A \cap B| + \epsilon}{|A| + |B| + \epsilon} \]

\[ = 1 - \frac{2\sum_i p_i g_i + \epsilon}{\sum_i p_i + \sum_i g_i + \epsilon} \]

where \(p_i \in [0,1]\) are predicted probabilities and \(g_i \in \{0,1\}\) are ground truth pixels. \(\epsilon = 10^{-6}\) prevents division by zero.

3.5.5 Segmentation Loss

We combine Dice and BCE:

\[ L_{seg} = \alpha \cdot L_{Dice} + (1-\alpha) \cdot L_{BCE}, \quad \alpha = 0.5 \]

Dice captures shape-level accuracy; BCE captures pixel-level accuracy.

3.6 Evaluation Metrics

3.6.1 Dice Coefficient and IoU

\[ \text{Dice} = \frac{2 \cdot TP}{2 \cdot TP + FP + FN}, \quad \text{IoU} = \frac{TP}{TP + FP + FN} \]

3.6.2 F1 Score and AUC

\[ F1 = \frac{2 \cdot \text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}} \]

AUC (Area Under the ROC Curve) measures discrimination ability across all thresholds. AUC = 0.5 is random; AUC = 1.0 is perfect.

Tier 1 — Tumor Detection (binary):

Class Count Ratio

Severely imbalanced (17:1 ratio). Class weights are inversely proportional to frequency.

4.4 Class Imbalance Problem

When a dataset has many more samples of one class than another, a naive model learns to always predict the majority class. Solutions used in BoneMTL:

  • Weighted loss: multiply loss of minority class by \(w \propto \frac{1}{\text{frequency}}\)
  • Focal Loss: down-weight easy majority examples automatically

5 Methodology

5.1 BoneMTL Architecture

Input (3, 256, 256)
    ↓
ResNet50 Encoder (pretrained ImageNet, shared)
    enc0: (64,  128, 128)   — stem
    enc1: (256,  64,  64)   — stage 1
    enc2: (512,  32,  32)   — stage 2
    enc3: (1024, 16,  16)   — stage 3
    enc4: (2048,  8,   8)   — stage 4
    ↓                  ↓
Classification      Segmentation
    Head               Decoder (U-Net)
    GAP → 512          dec4, dec3, dec2, dec1, dec0
    fc_tier1 (1)       seg_out (1, 256, 256)
    fc_tier2 (1)
    fc_tier3 (9)

Total parameters: 33,573,372

The shared encoder extracts features used by both tasks. Shared representations act as implicit regularization — the segmentation task helps the classification task locate tumors, and vice versa.

5.2 Multi-task Loss

\[ L = \lambda_1 L_{tier1} + \lambda_2 L_{tier2} + \lambda_3 L_{tier3} + \lambda_4 L_{seg} \]

Component Loss Notes
\(L_{tier1}\) BCE All samples
\(L_{tier2}\) Weighted BCE, \(w=4.5\) Tumor samples only
\(L_{tier3}\) Focal Loss, \(\gamma=2.0\) Tumor samples only
\(L_{seg}\) \(0.5 \cdot L_{Dice} + 0.5 \cdot L_{BCE}\) Masked samples only

Augmentation (training only):

  • Horizontal flip (\(p=0.5\))

  • Normalize with ImageNet mean/std

7 Discussion

7.1 What Worked

Focal Loss for Tier 3: The 17:1 class imbalance in Tier 3 makes standard CrossEntropy ineffective — the model learns to predict only the majority class (osteochondroma). Focal Loss down-weights easy majority examples and forces the model to learn from rare classes, improving F1 macro from 0.4334 to 0.4526.

Increased \(\lambda_{seg}\): Setting \(\lambda_{seg}=2.0\) forces the shared encoder to learn spatially precise features useful for segmentation. This also benefits classification since localization is implicitly learned.

Pretrained backbone: ImageNet pretraining provides strong low-level features (edges, textures) that transfer well to X-ray images, significantly reducing training time and improving generalization.

7.2 Limitations

  1. Segmentation Dice 0.47: Still far from clinical utility. Dice > 0.65 is typically needed for clinical segmentation tasks.
  2. Tier 3 F1 0.45: 9-class classification with severe imbalance remains difficult. More data for rare classes (osteofibroma: 44 cases) would help significantly.
  3. Single dataset: Results may not generalize to other hospitals or X-ray equipment.
  4. No explainability: Model decisions are not interpretable — a limitation for clinical deployment.

8 Conclusion

We presented BoneMTL, a multi-task framework for simultaneous bone tumor segmentation and hierarchical classification. Key findings:

  • Multi-task learning with shared ResNet50 encoder effectively combines segmentation and classification
  • Focal Loss with \(\gamma=2.0\) improves performance on severely imbalanced 9-class Tier 3
  • Increasing \(\lambda_{seg}=2.0\) improves segmentation without hurting classification
  • Fine-tuning from a pretrained checkpoint outperforms training from scratch

Future work includes Attention U-Net for segmentation, cross-validation for robust evaluation, and Grad-CAM explainability for clinical interpretability.
